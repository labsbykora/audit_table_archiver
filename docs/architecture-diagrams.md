## Read Replica Load Balancing Flow

```
┌─────────────────────────────────────────────────────────────┐
│                    Query Classification                       │
│                                                              │
│  SELECT query? ──Yes──→ Use Replica                         │
│       │                                                    │
│       No                                                   │
│       │                                                    │
│       └──→ Use Primary (DELETE, VACUUM, etc.)              │
└─────────────────────────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────────────────────┐
│              Replica Selection Strategy                      │
│                                                              │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐     │
│  │ Round-Robin  │  │   Least      │  │  Lag-Aware   │     │
│  │              │  │ Connections  │  │              │     │
│  └──────────────┘  └──────────────┘  └──────────────┘     │

                    │
                    ▼

│                  Health Check & Selection                    │

```

## S3 Upload Pipeline (Async)

```
┌─────────────────────────────────────────────────────────────┐
│              Batch Processing (Synchronous)                  │
│                                                              │
│  1. Select Batch (Replica)                                   │
│  2. Serialize to JSONL                                       │
│  3. Compress (gzip)                                          │
│  4. Start Upload (Async) ───────────────┐                  │
│  5. Continue to next batch                │                  │
└───────────────────────────────────────────┼──────────────────┘
                                            │
                                            ▼
                            ┌───────────────────────────────┐
                            │    Upload Pipeline             │
                            │                                │
                            │  ┌──────────┐  ┌──────────┐   │
                            │  │ Upload 1 │  │ Upload 2 │   │
                            │  │  Task    │  │  Task    │   │
                            │  └──────────┘  └──────────┘   │
                            │                                │
                            │  Thread Pool (max 2-5)         │
                            └───────────────────────────────┘
                                            │
                                            ▼
                            ┌───────────────────────────────┐
                            │         S3 Bucket              │
                            │                                │
                            │  archives/                      │
                            │    database/                    │
                            │      table/                     │
                            │        batch_001.jsonl.gz       │
                            │        batch_002.jsonl.gz       │
                            └───────────────────────────────┘
```
